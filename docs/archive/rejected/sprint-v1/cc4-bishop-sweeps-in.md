## Rejection record

- **Decision.** REJECTED.
- **Phase.** Phase 2 (independent R0 check during reviewer audit).
- **Reviewer.** Author self-audit, lead-aligned per *çok agresif ol* + *R0 konusunda taviz verme*.
- **Check that failed.** R0 — *instinct vs. memory* with the new candidate CC2 as the reference.
- **Rationale.** CC4 and CC2 are **the same motif-instinct exercise** under different cosmetics:
  - Both use a bishop as the rescuer
  - Both deliver check by **capturing a kingside black pawn**
  - Both end on a square adjacent to bK and attack bK via a one-step diagonal
  - The tactical idea ("capture the kingside shield with check") is identical

  A trained CC2-veteran would IMMEDIATELY apply the same idea to CC4 — they wouldn't catch a fresh motif; they'd recognize the now-familiar "bishop captures shield pawn" pattern. Shipping both CC2 and CC4 fails R0 **between the new positions themselves**.

  Between CC2 and CC4, CC2 is the stronger of the pair (Bxf7+ is a more classic chess tactical motif; the f7 pawn weakness is more memorable than the h7 pawn weakness in opening theory).
- **Future-sprint guidance.** When evaluating multiple candidates within the same motif, treat them as competing for ONE slot — only the strongest survives. If two candidates produce the same instinct exercise, ship one.

  For a future bishop-counter-check candidate, distinguish from CC2 by using a fundamentally different *mechanism*, not just a different capture square. Options:
  - Bishop check via discovered attack (bishop moves off a line; revealed queen/rook delivers check)
  - Bishop check from a diagonal that doesn't involve capturing the shield
  - Bishop check that simultaneously blocks the threat's line (a counter-check + block combination)
